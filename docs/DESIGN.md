# BerryLauncher 设计语言 v2 —「Quiet Forest / 静林」

定稿于 2026-10，替代 0.1.x 的玻璃拟态 + 网格 + 光晕风格。
实现入口：`src/renderer/design.css`（覆盖 `styles.css` 的旧视觉，新组件直接写在这里）。

## 1. 原则

1. **界面是平的，控件是凸的。** 画布只有纯色和 1px 边框；按钮、输入框、下拉、分段选择这些可操作控件带轻微内高光、外投影和浅色描边，像从平面上长出来。
2. **一个强调色。** 固定森林绿，不做主题色切换。绿色只用于主操作、当前导航、焦点、进度、关键数字。
3. **品牌只出现在该出现的地方。** 像素浆果 logo 出现在标题栏、关于页、空状态；不用像素纹理铺背景。
4. **层级靠表面与间距，不靠阴影与模糊。** 卡片之间用 `surface / surface-2 / surface-3` 和 8px 间距区分。
5. **信息优先。** 页面标题 22px，正文 13px；不写 40px 海报标题，不做无限浮动动画。

## 2. Tokens

### 颜色（深色）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#0A0D0B` | 应用背景 |
| `--surface` | `#111512` | 卡片、面板 |
| `--surface-2` | `#171C18` | 次级表面、hover |
| `--surface-3` | `#1D241F` | 输入框/分段选择/凸起控件底 |
| `--line` | `rgba(255,255,255,.07)` | 常规边框 |
| `--line-strong` | `rgba(255,255,255,.13)` | 控件边框、分隔 |
| `--text` | `#EDF2EE` | 主文字 |
| `--text-dim` | `#A6B4AA` | 次要文字 |
| `--text-mute` | `#738077` | 说明、元信息 |
| `--accent` | `#3DDC84` | 主色 |
| `--accent-bright` | `#5CE89A` | 主色高光 |
| `--accent-strong` | `#2FBF70` | 主色阴影面 |
| `--on-accent` | `#06130B` | 绿底文字 |
| `--danger` | `#F87171` | 危险 |

浅色模式保持同一结构：`#F5F7F4` 背景、`#FFFFFF` 表面、`#DCE5DB` 边框、`#16211A` 文字。

### 字体

- 字体：Segoe UI Variable / Noto Sans SC / system-ui
- 等宽：JetBrains Mono / Cascadia Code / Consolas（版本号、日志、路径）
- 字阶：11（辅助）、13（正文）、15（卡片标题）、22（页面标题）、26（首页 hero）
- 字重：400 / 500 / 600 / 700

### 间距与圆角

- 间距：4 / 8 / 12 / 16 / 24 / 32
- 页面内边距：24 28；卡片内边距：14–20
- 圆角：输入框 10、卡片 14、弹窗 18、**按钮 999（胶囊）**、icon 按钮 999

### 凸起控件规范（核心）

所有强调色按钮：

```css
background: linear-gradient(180deg, #63EDA3 0%, #3DDC84 52%, #2CBA6B 100%);
border: 1px solid rgba(255, 255, 255, 0.6);   /* 极细浅色描边 */
box-shadow:
  inset 0 1px 0 rgba(255, 255, 255, 0.55),    /* 顶部高光 */
  inset 0 -1px 0 rgba(0, 0, 0, 0.14),         /* 底部暗边 */
  0 3px 10px rgba(61, 220, 132, 0.22);        /* 落地阴影 */
```

- 次级按钮：`surface-3 → surface-2` 渐变 + `--line-strong` 描边 + 顶部内高光。
- 幽灵按钮：无背景无阴影，hover 时给 `surface-2`。
- 危险按钮：红底 + 同样浅色描边。
- hover：上浮 1px、阴影加深；active：下沉 1px、内阴影加强。
- 图标按钮：圆形，hover 给 `surface-2` + 边框。

## 3. 布局

- 标题栏 46px，侧栏 204px，内容区最小 24px 内边距，最大内容宽 1180px。
- 侧栏底部是账户卡与版本号；任何浮层都不能盖住它。
- 控制台是**内容区内的 dock**，不是 `position: fixed` 浮层：
  - `hidden`：完全隐藏；
  - `peek`：38px 状态条（实例、状态、PID/退出码、日志行数、展开/关闭）；
  - `open`：240px 日志区。
- 日志开关：标题栏终端图标 + 控制台头部；设置里提供「启动时展开控制台」。

## 4. 组件

- 卡片：`surface` + 1px `--line`，无模糊、无阴影；hover 只变边框。
- 列表行：48–50px 高，hover 用 `surface-2`。
- 模态：18px 圆角、`--line-strong` 边框，唯一使用大阴影的地方。
- Toast：右下/右上浮层，`surface-2` + 阴影。
- 分段选择：胶囊容器 + 胶囊选项，选中项 `surface-3` + 绿色圆点。
- 徽章：20px 高，胶囊，默认中性；绿色仅用于「已安装 / 运行中 / 整合包」。

## 5. 禁止

- 背景网格、噪点、径向光晕、漂浮方块、虚线环。
- 渐变文字、彩色发光边框、玻璃模糊卡片。
- 一个页面出现第二个强调色（红/黄只用于状态）。
- 新增圆角/字号/间距的「一次性值」；必须复用上面的 token。
